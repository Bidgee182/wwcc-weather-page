CIM 500 Configuration

Step 1 - Set the rotary switch to Modbus TCP
Locate the CIM 500 module inside the CU 352 panel. It has a small rotary dial on the front face with positions 0 through F.

Turn the dial to position 2 (Modbus TCP/IP over Ethernet).
Factory default is position 0 (GRM cloud) - you are changing it to 2.

Power cycle the CIM 500 after changing the switch (switch off the CU 352 panel isolator for 10 seconds, then back on).
Step 2 - Connect Ethernet to USR G806 Router
Plug a Cat5e/Cat6 cable from the RJ45 port on the CIM 500 into one of the LAN ports on the USR G806 router. The CIM 500 will request an IP address from the router via DHCP. Check the router's connected device list to find the IP assigned to the CIM 500 (look for a device named "Grundfos" or "CIM500").

Recommended: assign a static/reserved IP to the CIM 500 in the router settings so it doesn't change. Example: 192.168.1.100

Modbus TCP port: 502
Modbus Unit ID (Slave Address): 1
Step 3 - Port Forward on USR G806
In the USR G806 admin panel, set up a port forward:
External port 502 -> Internal IP of CIM 500 port 502 (TCP)

This allows the GitHub Actions polling script to reach the CIM 500 over the 4G connection. The 4G SIM's public IP will be polled every 5 minutes.

Optional: Set up DDNS on the USR G806 if the 4G SIM IP changes frequently (most 4G SIMs have a dynamic public IP).
Step 4 - Poller Script (GitHub Actions)
A Python script using the pymodbus library will run every 5 minutes via GitHub Actions. It reads the CIM 500 Modbus registers over TCP, converts the values to engineering units, and writes them to data/pump_station_latest.json in this repository. This page auto-refreshes every 60 seconds to pick up new data. Once the router and CIM 500 are connected and the script is running, this page will update automatically.
