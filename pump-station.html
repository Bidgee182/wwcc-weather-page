CIM 500 Configuration

Step 1 - Set rotary switch to position 2 (Modbus TCP)
Inside the CU 352 panel, find the CIM 500 module. It has a small rotary dial labelled 0 to F. Turn it from 0 (GRM cloud default) to 2 (Modbus TCP/IP over Ethernet). Use a small flat-head screwdriver.

Power cycle the panel after changing (isolator off 10s, then back on).
Step 2 - Ethernet from CIM 500 to USR G806 LAN port
Cat5e/Cat6 cable from the RJ45 port on the CIM 500 into any LAN port on the USR G806. The CIM 500 will request an IP from the router via DHCP.

Check the router's DHCP client list to find the CIM 500 IP (look for device name "Grundfos" or "CIM500"). Then set a static/reserved IP for it - e.g. 192.168.1.100
Step 3 - Port forward on USR G806
In the G806 admin panel: Port Forward → add rule:
External port 502 → Internal 192.168.1.100:502 (TCP)

This lets the GitHub Actions poller script read Modbus TCP from the CIM 500 over the 4G connection.
Step 4 - Poller script (next step)
A Python script using pymodbus will run via GitHub Actions every 5 minutes. It reads all CIM 500 Modbus registers and writes to three files:
data/pump_station_latest.json - current state + 24h history
data/pump_station_history.json - 90-day rolling history (15-min)
data/pump_station_daily.json - daily summaries

This page refreshes automatically every 60 seconds.

Data File Schema Reference

latest.json - Current state + 24h history (5-min readings)
history.json - 90-day rolling log (15-min readings): ts, pa, ps, fl, nr, sp[5], pw[5]
daily.json - Daily summaries: date, p_min, p_max, p_avg, fl_max, fl_total, hrs[5], sts[5], kwh[5]

Compact history fields:
ts=timestamp • pa=pressure actual • ps=pressure setpoint
fl=flow m³/h • nr=pumps running • sp=speeds[%] • pw=power[kW]
